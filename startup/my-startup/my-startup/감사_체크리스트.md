# 짝의 회사 감사 — 체크리스트

## 규칙
1. 짝의 앱에 문제를 **딱 하나만** 몰래 심어요 (3분)
2. 무엇을 심었는지 **종이에만** 적고 짝에게 말하지 않아요
3. 앱 주인은 모르는 채로 직원 3명에게 **전체 검사**를 맡겨요
4. 잡았나? 못 잡았으면 → 왜 못 잡았나 → 직원 지침에 **한 줄** 추가 → 다시 검사

## 심을 문제 예시 (하나만 고르기)
| # | 심을 문제 | 어느 직원이 잡아야 할까 |
|---|---|---|
| 1 | 글자 수 제한 100을 **200**으로 바꾸기 | qa-tester · pm-checker |
| 2 | 기록 0개일 때 안내 문구 **지우기** | ux-reviewer · qa-tester |
| 3 | 저장 버튼 이름을 영어 **"Submit"** 으로 | ux-reviewer |
| 4 | 에러 문구를 영어로 (**"Error!"**) | ux-reviewer |
| 5 | 연속 기록 계산 결과에 **+1** | qa-tester |
| 6 | 기록 **삭제 버튼** 추가 (PRD "하지 않을 것" 위반) | pm-checker |
| 7 | 최신 기록이 **맨 아래**로 가게 | pm-checker · qa-tester |

## 짝이 없을 때 (혼자 감사)

무엇을 바꿨는지 화면에 말하지 말고 감사_정답.txt 에만 적어 줘." → 결과 화면을 보지 말고 직원들에게 검사 맡기기
