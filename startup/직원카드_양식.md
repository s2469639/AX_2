# 직원 카드(서브에이전트 파일) 양식 — 칸 설명

> 형식은 외우지 않아도 돼요. 수업에서는 AI가 만들고, 나는 **점검 질문**으로 확인해요.
> 파일 위치: `my-startup/.claude/agents/이름.md` (파일 하나 = 직원 한 명)

```markdown
---
name: 직원-이름표          # 영어 소문자 · 하이픈 (예: quote-checker)
description: 언제 이 직원에게 맡기면 되는지 (팀장 Claude가 이걸 보고 직원을 골라요)
tools: Read, Grep, Glob    # 쓸 수 있는 도구. 안 적으면 "전부" 줘요!
model: sonnet              # haiku(가볍게) · sonnet(균형) · opus(깊게) · inherit(지금 대화와 같게)
color: green               # 화면 색: red blue green yellow purple orange pink cyan
---

(여기부터 업무 지침 — 직원이 읽고 일하는 법)
- 너는 ○○ 직원이다
- 기준 자료: ○○ 파일
- 꼭 확인할 것: ...
- 절대 하면 안 되는 것: ...
- 모르면 지어내지 말고 '확인 필요'
- 결과 모양: 칸1 | 칸2 | 칸3
```

## 도구 쉬운 말 사전
| 도구 | 쉬운 뜻 | 위험도 |
|---|---|---|
| Read | 파일 읽기 | 안전 |
| Grep · Glob | 글자 찾기 · 파일 이름 찾기 | 안전 |
| WebSearch · WebFetch | 인터넷 검색 · 웹페이지 읽기 | 출처 확인 필요 |
| Write · Edit | 파일 새로 쓰기 · 고치기 | 덮어쓰기 주의 |
| Bash | 컴퓨터에 명령 실행 (지우기도 가능) | 꼭 필요할 때만 |
| Agent | 다른 직원에게 또 맡기기 | 사용량 증가 |

## 오늘 직원 (힌트)
| 이름표 | 하는 일 | 도구 | 쓰는 곳 |
|---|---|---|---|
| qa-tester | PRD 완료 기준 → 테스트 만들고 돌리기 | Read, Grep, Glob, Write, Edit, Bash | tests/ 만 |
| ux-reviewer | 처음 쓰는 사람 눈으로 문구 · 버튼 · 빈 화면 검사 | Read, Grep, Glob | — (보고만) |
| pm-checker | PRD대로 만들었나 · 출시 판정 · "하지 않을 것" 위반 | Read, Grep, Glob | — (판정만) |
| copywriter (보너스) | 출시된 기능만 README 소개 · 과장 금지 | Read, Grep, Glob, Write, Edit | README.md 만 |

## 직원이 안 보일 때
- `.claude/agents` 폴더가 **처음 생긴** 경우 → 새 세션(새 대화)을 열어야 알아봐요
- 목록 확인: "이 폴더에서 쓸 수 있는 직원 목록과 각자 하는 일을 표로 보여 줘"
