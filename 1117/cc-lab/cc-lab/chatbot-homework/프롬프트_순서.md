# Claude Code 에 차례대로 (Code 탭 → 폴더: chatbot-homework)

## 🚀 시작 — 한 문단으로 "무엇을 만들지" 말하기 (예시를 내 것으로 바꾸기)
나는 RAG, LangChain, LangGraph 를 이용한 개인 챗봇 웹앱을 만들 거야.
- 주제: (예) 무역 용어와 내 수업 노트를 물어보면 data/ 문서를 근거로 답해 주는 "무역 공부 도우미"
- 사용자: 나 (비전공자 무역 취업 준비생)
- 화면: Streamlit 채팅 — 답 아래에 출처(파일 이름) 표시
- AI: OpenAI API (대화 OPENAI_MODEL, 임베딩 OPENAI_EMBED_MODEL — .env 에서 읽기)
- 흐름: LangGraph 로 retrieve → generate (도전: 자료가 부족하면 질문을 바꿔 다시 검색)
- 규칙: 문서에 없으면 "문서에서 찾지 못했어요" 라고 답하기
CLAUDE.md, .claude/rules/, DESIGN.md, 과제_안내.md 를 읽고 이대로 진행할 계획만 세워 줘. 아직 코드는 만들지 마. (계획 모드)

## 1. 환경
파이썬 가상환경(.venv)을 만들고 requirements.txt 를 만들어 설치해 줘. (streamlit, langchain, langchain-openai, langgraph, langchain-chroma 또는 faiss, python-dotenv) 버전은 지금 최신 안정판으로, 설치한 버전을 requirements.txt 에 적어 줘.

## 2. 키 (내 손으로)
.env.example 을 .env 로 복사만 해 줘. 키는 내가 직접 넣을게. .env 내용은 읽거나 출력하지 마.

## 3. RAG — 문서 넣기
data/ 의 .md 문서를 불러와 500글자 정도로 자르고, OPENAI_EMBED_MODEL 로 임베딩해서 로컬 벡터 저장소(chroma_db/)에 저장하는 ingest.py 를 만들어 줘.
- 각 단계에 비전공자용 한국어 주석
- 끝나면 "문서 몇 개 → 조각 몇 개 저장" 만 출력
- 이미 저장돼 있으면 다시 임베딩하지 않게 (비용 절약)

## 4. LangGraph — 흐름
graph.py 에 LangGraph 그래프를 만들어 줘.
- 상태(state): question, docs, answer, sources
- retrieve 노드: 질문과 비슷한 조각 4개 찾기
- generate 노드: 찾은 조각만 근거로 OPENAI_MODEL 로 답하기, 근거가 없으면 "문서에서 찾지 못했어요"
- START → retrieve → generate → END
- LangChain · LangGraph 최신 사용법은 DeepWiki 로 확인하고, 그래프 그림(mermaid)도 README 에

## 5. 웹앱
Streamlit 채팅 화면 app.py 를 만들어 줘. graph.py 를 불러서 답하고, 답 아래 출처(파일 이름) 표시, 대화 기록 유지, DESIGN.md 색 · 글꼴 적용.

## 6. 점검
필수 항목 7가지를 표로 점검하고, 안 된 것만 하나씩 고쳐 줘. 시험 질문 3개(문서에 있는 것 2 · 없는 것 1)로 확인하고 결과를 보여 줘.

## 🌟 도전
graph.py 에 조건 엣지를 추가해 줘: retrieve 결과가 질문과 관련이 적으면 rewrite 노드에서 질문을 바꿔 한 번만 다시 retrieve. 그래프 그림도 README 에 업데이트.
