# 📚 오늘 과제 — "내 문서로 답하는 개인 챗봇" 웹앱 (RAG · LangChain · LangGraph)

## 1. 무엇을 만드나요?
내가 넣은 문서(`data/` 폴더)를 **찾아 읽고** 그 내용을 근거로 답하는 챗봇 웹앱.
- 웹 화면: **Streamlit** (파이썬으로 만드는 간단한 웹앱)
- 문서 찾기: **RAG** (문서를 잘게 나눠 저장 → 질문과 비슷한 조각을 찾아 → AI 에게 같이 줌)
- 부품: **LangChain** (문서 불러오기 · 자르기 · 임베딩 · 검색 · AI 모델 연결)
- 흐름: **LangGraph** (검색 → 답변 → (필요하면) 다시 검색 … 순서도를 코드로)

## 3. 꼭 들어가야 할 것 (필수)
1. `data/` 의 문서를 불러와 **조각내고(chunk) 벡터로 저장** (RAG)
2. 질문 → **관련 조각 검색** → 그 조각을 근거로 **답변**
3. 답변 아래에 **출처(어느 파일의 어느 부분)** 표시
4. 문서에 없는 내용이면 **"문서에서 찾지 못했어요"** 라고 답하기 (지어내지 않기)
5. **LangGraph** 로 흐름 만들기 — 최소 노드 2개 (예: `retrieve` → `generate`)
6. Streamlit 채팅 화면 · 대화 기록 유지
7. `DESIGN.md` 의 색 · 글꼴 규칙 적용

## 4. 도전 (선택)
- 검색 결과가 부족하면 질문을 바꿔 **다시 검색**하는 노드 (LangGraph 조건 분기)
- 문서 업로드 버튼 · PDF 지원
- 대화 요약 메모리
