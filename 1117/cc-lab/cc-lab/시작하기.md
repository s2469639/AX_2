# cc-lab — Claude Code · MCP · md · rules 실습 폴더

1. `cc-lab.zip` 을 **바탕화면**에 압축 풀기
2. Claude 데스크톱 앱 → **Code** 탭 → 환경 **Local** → 폴더 열기(Open folder…) → `cc-lab`
3. 교안의 프롬프트를 복사 → 붙여 넣기 → Enter

| 폴더 | 실습 |
|---|---|
| `01_첫세션/` | Claude Code 와 첫 대화 · 권한 모드 · 계획 모드 |
| `02_마크다운/` | 마크다운 1분 연습 |
| `03_팀프로젝트/` | CLAUDE.md · rules · AGENTS.md 를 팀 프로젝트처럼 |
| `04_DESIGN/` | DESIGN.md 만들고 검사하기 |
| `chatbot-homework/` | **오늘 과제** — RAG · LangChain · LangGraph 개인 챗봇 웹앱 |

## 🔐 규칙
- API 키는 **`.env` 파일에 내 손으로만**. 채팅 · 스크린샷 · GitHub 에 붙여 넣지 않기
- 모르는 MCP 서버는 연결하지 않기 — **공식(만든 회사) 주소**인지 먼저 확인
- 회사 · 개인의 실제 문서는 과제에 넣지 않기 (예시 문서는 모두 **(가상)**)
