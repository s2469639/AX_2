## 2) LangGraph 가장 짧은 예 (StateGraph · 노드 · 엣지 · START/END)

```python
from typing_extensions import TypedDict
from langgraph.graph import END, START, StateGraph

class State(TypedDict):
    value: int

def increment(state: State) -> dict:
    return {"value": state["value"] + 1}

builder = StateGraph(State)
builder.add_node("increment", increment)
builder.add_edge(START, "increment")
builder.add_edge("increment", END)
graph = builder.compile()

print(graph.invoke({"value": 1}))  # {'value': 2}
```

- `START`, `END`, `StateGraph`는 모두 `langgraph.graph`에서 가져옵니다.
- 노드는 상태를 읽고 바뀐 부분만 돌려주는 함수이고, 엣지는 `add_edge`로 순서를 잇습니다. `compile()` 전에는 실행할 수 없습니다.
- 근거: DeepWiki가 든 위키 문서는 **Functional API (@task and @entrypoint)**이고, 직접적인 코드 근거는 `libs/langgraph/langgraph/graph/state.py`와 테스트 파일이라고 합니다. 위키 문서가 이 예시를 직접 설명하는지는 **확인 필요**입니다.
- 개념 설명(노드·엣지·상태)의 근거 문서: Overview, Glossary

DeepWiki 검색: https://deepwiki.com/search/584cbf26-eb8d-4f4a-a217-a170895cf7a8

## 3) ChatOpenAI로 OpenAI 모델 부르기 (모델 이름은 .env에서)

`.env`

```dotenv
OPENAI_API_KEY=your-api-key
OPENAI_MODEL=gpt-4o
```

```python
import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()
model = ChatOpenAI(model=os.environ["OPENAI_MODEL"])
response = model.invoke("안녕하세요")
```

- 확인된 것: `ChatOpenAI`는 `langchain_openai`에서 import합니다. 생성자 인자 이름은 `model`이고 실제 필드 `model_name`의 별칭입니다. `OPENAI_API_KEY`는 환경 변수에서 읽는 것을 전제로 합니다.
- 위키에 없는 부분: `load_dotenv()`(python-dotenv)는 `.env`를 읽기 위해 덧붙인 일반적인 설정입니다. `OPENAI_MODEL`은 앱에서 정한 변수 이름이고, `gpt-4o`는 예시 값입니다. 실제 사용할 모델 이름은 **확인 필요**입니다.
- `ChatOpenAI`가 `OPENAI_API_KEY`를 자동으로 읽는지 세부 동작은 실행해 확인하지 않았습니다.
- 근거: "OpenAI Integration: ChatOpenAI and Azure Support" (`openwiki/openai-provider.md`), OpenAI Integration

DeepWiki 검색: https://deepwiki.com/search/a4674fa4-61a5-43c9-9b7b-5868da3f76f6
