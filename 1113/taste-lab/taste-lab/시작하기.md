# taste-lab — 디자인 감각 스킬 실습 폴더

1. 이 폴더를 **문서** 폴더에 풀어요 → `문서/taste-lab`
2. Claude 데스크톱 앱 → **Code** 탭 → 새 세션 → 폴더 `taste-lab` 선택
3. 실습 ①②는 `before/` · `after/` 폴더에 만들어요
4. 최종 실습은 내 서비스 폴더에서 (예: 지난 시간 만든 서비스 폴더) — 없으면 여기 `my-service/` 에서
5. 양식은 `양식/` 폴더 — 빈칸을 채워 쓰는 실습용이에요

⚠️ 스킬은 남이 만든 "작업 지시서 + 도구"예요. 설치 전에 **누가 만들었는지 · 안에 무엇이 들어 있는지** 꼭 확인해요.
