## A. 출퇴근 직장인

**첫 화면 한 줄:** 출근길 커피, 점심까지

**문제**
아침에 내린 커피, 책상에 앉아 한 모금 마시려고 하면 벌써 식어 있어요. 회의 하나 끝나고 나면 한 잔을 다 데워 마시고 싶어지죠.

**해결**
오름 써모 텀블러는 보온 6시간. 출근길에 담은 커피를 점심 무렵까지 따뜻하게 마실 수 있어요. 뚜껑은 원터치라 한 손으로 열어요.

**근거**
- 보온 6시간: 자체 시험 결과, 실온 20℃에서 95℃ 물을 담고 6시간 뒤 62℃ (공인 기관 시험 아님, 자체 시험)
- 뚜껑 트라이탄(BPA free), 내부 스테인리스 316
- 식품용 기구 적합 (KC)

**제품 정보**
| 항목 | 내용 |
|---|---|
| 용량 · 무게 · 높이 | 500ml · 320g · 21cm |
| 색상 | 크림 · 세이지 · 차콜 · 코랄 (4종) |
| 소재 | 내부 스테인리스 316 / 뚜껑 트라이탄(BPA free) |
| 보온 · 보냉 | 6시간 · 12시간 (시험 조건은 아래 FAQ 참고) |
| 기타 | 원터치 뚜껑 · 컵홀더 호환(지름 7cm) |
| 관리 | 식기세척기 사용 불가 (뚜껑만 가능) |

**FAQ**
1. **정말 6시간 따뜻한가요?** 자체 시험 기준이에요. 실온 20℃에서 95℃ 물을 담았을 때 6시간 뒤 62℃였어요. 실제 사용 환경에 따라 달라질 수 있어요.
2. **차량 컵홀더에 들어가나요?** 지름 7cm 컵홀더와 호환돼요. 쓰시는 컵홀더 크기를 먼저 확인해 주세요.
3. **식기세척기에 넣어도 되나요?** 본체는 안 돼요. 뚜껑만 식기세척기 사용이 가능해요.

**구매 유도**
출시 기념 10% 할인으로 **28,800원** (정가 32,000원, **11월 30일까지**). 영문 10자 각인은 무료예요. 스마트스토어 · 쿠팡에서 만나보세요.
