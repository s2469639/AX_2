# 뉴스 브리핑 만들기

CLAUDE.md의 공통 규칙을 먼저 따른다. 결과는 `뉴스/결과/`에, 파일 이름은 `[오늘날짜]_브리핑.html` (예: 2026-11-09_브리핑.html).

## 1. 설정 읽기
`뉴스/뉴스_관심키워드.md`를 읽는다. 이 파일이 기준이고, 아래 내용은 코드에 박지 말고 매번 여기서 읽는다.
- **관심 키워드**: 키워드마다 한 줄. 앞에 `(영어)`가 붙은 줄은 영어 키워드.
- **빼고 싶은 것**: 제외 기준 (예: 연예 · 스포츠, 광고성 보도자료, 같은 내용 반복).
- **결과 모양**: 키워드별 개수, 총 개수 한도, 기사마다 넣을 항목, "오늘의 한 줄" 여부.

`뉴스/보낸기사.txt`를 읽는다. `#`으로 시작하는 줄은 설명이라 무시하고, 나머지는 이미 정리한 기사 주소다.

## 2. 구글 뉴스 RSS 가져오기
키워드마다 RSS를 가져온다. 최근 1일만 본다.
- 한국어: `https://news.google.com/rss/search?q=<키워드> when:1d&hl=ko&gl=KR&ceid=KR:ko`
- 영어 키워드: `...&hl=en-US&gl=US&ceid=US:en`
- **한글 키워드를 주소에 직접 쓰지 않는다.** Windows의 Git Bash에서 `curl`에 한글을 넣으면 글자가 깨져 엉뚱한 검색이 된다. Python `urllib.parse.quote()`로 퍼센트 인코딩해서 `urllib.request`로 가져온다 (User-Agent 지정).
- 각 항목에서 제목 · 언론사(`source`) · 링크 · 발행일을 읽는다.

## 3. 거르고 고르기
1. `보낸기사.txt`에 있는 주소는 뺀다.
2. 설정 파일의 "빼고 싶은 것" 기준으로 뺀다. 같은 내용을 여러 매체가 쓴 기사는 관점이 다른 것 하나만 남긴다.
3. 설정 파일의 개수 규칙(키워드별 · 총 한도)을 지켜 고른다. 우리 회사(화장품 · 생활용품을 동남아로 수출)와 관련이 큰 기사를 우선한다.
4. 키워드 결과가 0건이면 억지로 채우지 않는다. 브리핑에 "최근 1일 0건"이라고 적고, 기간을 넓힐지는 사용자에게 묻는다 (임의로 기간을 바꾸지 않는다).

## 4. 기사마다 쓸 것
- **제목**: 한국어 기사는 그대로, 영어 기사는 영어 원문 그대로. 끝의 ` - 언론사` 꼬리는 떼고 언론사는 따로 쓴다.
- **언론사**
- **한 줄 요약**: RSS에 나온 내용(제목 · 언론사)만 근거로 쓴다. RSS는 본문이 없어서 제목을 풀어 쓰는 수준이다. 본문을 읽지 않았으면 브리핑 끝에 그렇게 밝힌다. 영어 기사의 요약 · 의미는 한국어로 쓴다.
- **우리 회사에 주는 의미**: 한 줄. 기사에 직접 없는 연결은 `(해석)`을 붙이고, 모르면 지어내지 말고 `[확인 필요]`.
- **링크**: RSS의 `link`를 그대로 쓴다 (구글 뉴스를 거쳐 원문으로 넘어가는 주소).

맨 위에 "오늘의 한 줄" 1개를 쓴다 (설정 파일에 있으면). 기사에 나온 사실만으로 쓴다.

## 5. 저장
1. `뉴스/결과/[오늘날짜]_브리핑.html`로 저장한다. 외부 라이브러리 없이 HTML · CSS만 쓰고, 폰 화면과 다크 모드에서도 보이게 한다.
2. 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 먼저 묻는다.
3. 브리핑을 저장한 **뒤에** 고른 기사의 링크를 `뉴스/보낸기사.txt`에 한 줄씩 추가한다. (파일 안의 기존 내용은 지우지 않는다.) 고르지 않은 기사는 추가하지 않는다.

## 6. 마무리 보고
채팅에는 키워드별로 몇 건 골랐는지, 0건인 키워드, "(해석)"이 붙은 의미가 있다는 점, 본문은 읽지 않았다는 점을 짧게 알린다.

## 하지 말 것
- 메일 발송이나 업로드 같은 밖으로 나가는 일 (브리핑 파일만 만든다).
- RSS에 없는 숫자 · 이름 · 날짜를 지어내기.
- 설정 파일이나 `보낸기사.txt`를 사용자 허락 없이 고치기 (`보낸기사.txt`에 기사 주소를 추가하는 것만 예외).
