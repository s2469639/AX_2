# 물품 공급 계약서 v1 (우리 초안, 2026-10-20) 조항별 요약

- 원본: `물품공급계약서_v1_우리초안.docx` (수정하지 않음)
- **갑 = 우리(주)오름트레이드(공급자), 을 = NOVA TRADING(구매자)**

| 조항 | 쉽게 말하면 (한 줄) | 돈 · 기한 · 책임 |
|---|---|---|
| 제1조 목적 | 우리가 선크림·수분크림을 팔고, 상대가 대금을 낸다는 계약임 | 책임 (계약 범위) |
| 제2조 물품과 수량 | 품목·수량·단가는 주문서(PO, 주문 한 건마다 쓰는 서류)로 정하고, 최소 주문은 품목당 1,000개임 | 돈 (최소 주문 규모) |
| 제3조 인도 조건 | 부산항에서 배에 실어 주는 조건(FOB, 선적 때까지 파는 쪽이 책임지는 방식)이고, 주문서 확인 후 45일 안에 선적해야 함 | 기한 (45일) · 책임 (부산항 선적까지) |
| 제4조 대금 지급 | 상대는 선적서류 발행일(B/L, 선적 증명서)로부터 30일 안에 미화(USD, 달러)로 우리 계좌에 보냄 | 돈 · 기한 (30일) |
| 제5조 품질 보증과 클레임 | 물건 도착 후 6개월 안에 불량을 서면으로 알리면, 우리가 확인 후 교환하거나 환불함 | 책임 (우리가 교환·환불) · 기한 (6개월) |
| 제6조 지체상금 | 우리가 선적 기한을 넘기면 늦은 하루마다 주문 금액의 0.1%를 물고, 최대 주문 금액의 10%까지임 | 책임 · 돈 (하루 0.1%, 상한 10%) · 기한 |
| 제7조 계약 기간 | 서명일부터 1년이고, 연장은 양쪽이 서면으로 합의해야 함 | 기한 (1년) |
| 제8조 계약 해지 | 한쪽이 계약을 어기고 서면 통지 후 30일 안에 고치지 않으면 상대가 계약을 끝낼 수 있음 | 책임 · 기한 (30일) |
| 제9조 분쟁 해결 | 다툼이 생기면 서울의 대한상사중재원(중재, 법원 대신 중재 기관이 판단하는 방식)에서 끝내고, 한국 법을 적용함 | 책임 (분쟁 처리 방식) |

## 참고
- 제3조의 "FOB 부산항 이후 운임·보험은 상대 부담"은 계약서에 직접 적혀 있지 않은 일반적인 무역 관례임. 필요하면 확인할 것. `[확인 필요]`
- 계약서에 없는 내용(단가, 총액, 서명일, 상대 담당자 등)은 쓰지 않았음. 서명란은 비어 있음.
