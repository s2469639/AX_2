# 우리 회사 계약 체크리스트 (해외영업팀 · 실습용)
| 항목 | 우리 기준 (OK) | 이러면 위험 |
|---|---|---|
| 대금 지급 | 선적일 기준 60일 이내 | 90일 이상 · "검수 후" 기준 · 검수 기간을 상대가 정함 |
| 인도 조건 | FOB · CIF | DDP (상대 나라 관세 · 통관까지 우리가 책임) |
| 품질 클레임 | 도착 후 12개월 이내 | 12개월 초과 · "즉시 전액 환불" |
| 지체상금 | 하루 0.1% 이하 · 상한 10% | 상한 없음 · 하루 0.2% 초과 |
| 계약 기간 | 1년 · 갱신은 서면 합의 | 자동 갱신 |
| 해지 | 양쪽이 같은 조건 | 한쪽만 이유 없이 해지 가능 |
| 분쟁 해결 | 대한상사중재원 · 서울 · 한국법 | 상대 나라 법원 · 상대 나라 법 |
| 독점 | 없음 (있다면 최소 구매량 보장과 함께) | 최소 구매량 없는 독점 |
