# GUESTLY — 프로젝트 공통 지침

## 프로젝트 개요

- **서비스명:** GUESTLY
- **한 줄 설명:** 한국을 방문하는 해외 바이어의 특성과 비즈니스 상황에 맞춰 식당과 선물을 추천하는 RAG 기반 의전 챗봇
- **주요 사용자:** 해외영업 담당자, 무역회사 직원, 해외 바이어 방문을 준비하는 실무자
- **목적:** LangChain, LangGraph, RAG, 임베딩·유사도 검색 실습 (상용 서비스가 아님)
- **형태:** Streamlit 채팅 웹 애플리케이션

## 핵심 원칙

1. 비즈니스 방문 상황에 특화된 추천만 한다 (일반 맛집·선물 추천 아님).
2. 모든 추천은 `data/` 문서에 근거하며 출처(파일명 > 소제목 > 줄 번호)를 함께 표시한다.
3. 근거가 부족하면 임의로 추천하지 않고 **"문서에서 찾지 못했어요"**를 반환한다. 이때 생성 모델을 호출하지 않는다.
4. 국가별 선호를 고정관념으로 판단하지 않는다. 개인 취향을 우선한다.
5. 반입 규정·영업 정보처럼 최신 확인이 필요한 내용은 단정하지 않고 "별도 확인 필요"로 안내한다.

## 기술 스택

| 구분 | 기술 |
|---|---|
| 언어 | Python 3.11+ (`.venv` 가상환경) |
| 화면 | Streamlit |
| LLM 연동 / 워크플로우 | LangChain / LangGraph |
| 벡터 저장소 | LangChain `InMemoryVectorStore` + JSON 파일 저장 (Chroma는 이 PC에서 실행 불가 — `조사노트.md` 참고) |
| AI API | OpenAI API만 사용 |
| 환경변수 | `.env` |

- 모델: `OPENAI_MODEL=gpt-6-luna`, `OPENAI_EMBED_MODEL=text-embedding-3-small` (둘 다 2026-11-17 최소 호출 테스트 통과)
- 처음 후보였던 `gpt-4.1-mini`와 GPT-5 mini는 공식 페이지에 Deprecated로 표시되어 바꿨다.
- `gpt-6-luna`는 추론 모델이므로 `reasoning_effort="none"`으로 고정한다. 기획서의 "미사용" 원칙에서 바꾼 것이며 사용자가 승인했다.

## 폴더 구조 (예정)

```
1117 실습/
├─ CLAUDE.md          # 이 문서 — 프로젝트 목적과 공통 원칙
├─ .claude/rules/     # 보안·코드 작성·API 비용 규칙
├─ DESIGN.md          # 서비스 설계, RAG 데이터 구조, LangGraph 흐름
├─ 과제_안내.md        # 실행 방법, 학습 목표, 평가 항목
├─ 조사노트.md         # 공식 문서 확인 결과, 오류·해결, 실험 기록
└─ data/              # 가상 연습용 Markdown 문서만 둔다
```

코드 파일(`ingest.py`, 앱 등)은 문서 설계 단계가 끝나고 사용자 승인 후 작성한다.

## 개발 규칙

1. `.env` 파일의 내용이나 API 키를 읽거나 출력하지 않는다.
2. API 키를 소스코드에 직접 작성하지 않는다.
3. `data/`에는 가상 연습 문서만 넣는다.
4. 한 번에 파일 하나씩 작성하거나 수정한다.
5. 파일을 수정한 후 변경 내용을 3줄로 요약한다.
6. 함수마다 한국어 주석을 한 줄 이상 작성한다.
7. 오류 메시지는 비전공자도 이해할 수 있는 쉬운 한국어로 작성한다.
8. 불필요한 외부 API 및 라이브러리를 추가하지 않는다.
9. 사용자 승인 없이 추가 기능을 확장하지 않는다.

세부 규칙은 `.claude/rules/`를 따른다.

## 검증 원칙

- 라이브러리 import 경로, 모델 사용 가능 여부, Chroma 점수 의미 등은 **설치된 버전 기준**으로 확인한 뒤 사용한다.
- 검증되지 않은 내용은 추측으로 확정하지 않고 `조사노트.md`에 "미검증"으로 기록한다.
- 확인 결과, 오류와 해결 과정, 실험 수치는 모두 `조사노트.md`에 남긴다.

## MVP 범위

- 포함: 비즈니스 식당 추천, 해외 바이어 선물 추천, 두 가지 통합 추천, 이전 조건을 유지한 후속 질문
- 제외: 실시간 예약, 실시간 가격·재고, 지도 API, 구매·결제, 자동 일정 관리, 다국어 음성 대화
