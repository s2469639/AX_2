# 보안 규칙

## API 키와 `.env`

- `.env` 파일을 열어 읽거나, 내용을 출력·복사·요약하지 않는다.
- API 키는 코드에서 `os.getenv("OPENAI_API_KEY")`처럼 환경변수로만 불러온다.
- API 키, 토큰을 소스코드·문서·로그·커밋 메시지에 직접 쓰지 않는다.
- 키가 없거나 잘못되었을 때는 키 값을 보여주지 않고 다음처럼 안내한다.
  - 예: "OpenAI API 키가 설정되지 않았어요. `.env` 파일에 `OPENAI_API_KEY`를 추가해 주세요."
- 예시 설정은 `.env.example`에 **빈 값**으로만 작성한다.

## Git 관리

- `.gitignore`에 다음을 포함한다: `.env`, `.venv/`, Chroma 저장 폴더, 사용량 기록 파일, `__pycache__/`.
- 키가 포함된 파일이 커밋될 위험이 보이면 작업을 멈추고 사용자에게 알린다.

## 데이터

- `data/`에는 가상 연습용 문서만 둔다. 문서 상단에 "가상 데이터"임을 명시한다.
- 실제 상호, 실존 인물, 고객·바이어 개인정보를 넣지 않는다.
- 사용자가 채팅에 입력한 내용을 외부 서비스(OpenAI API 제외)로 보내지 않는다.

## 로그

- 오류 로그와 사용량 기록에는 API 키·요청 헤더를 남기지 않는다.
- 사용량 기록에는 시각, 모델명, 토큰 수, 예상 비용만 저장한다.
