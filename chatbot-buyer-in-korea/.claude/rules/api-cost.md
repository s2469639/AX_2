# API 비용 관리 규칙

## 임베딩

- 임베딩은 `ingest.py`에서만 실행한다. 앱 실행 중에는 문서 임베딩을 하지 않는다 (사용자 질문 임베딩은 검색에 필요하므로 예외).
- 문서가 바뀌지 않았으면 기존 임베딩을 재사용한다.
- 바뀐 문서(또는 바뀐 조각)만 다시 임베딩한다. 변경 감지 방식은 `조사노트.md`에서 검증 후 확정한다.

## 검색과 생성

- 검색 문서 조각은 기본 **3개 내외**로 제한한다.
- 모델에 전달하는 최근 대화 메시지는 **최대 4개**로 제한한다.
- 재검색은 **최대 1회**만 허용한다.
- 자동 반복 호출과 무제한 재시도를 금지한다. API 오류 시 재시도하지 않고 사용자에게 안내한다.
- 근거가 부족하면 생성 모델을 호출하지 않고 "문서에서 찾지 못했어요"를 반환한다.
- 프롬프트는 짧고 명확하게 작성한다.

## 예산 (초기 제안)

| 구분 | 한도 |
|---|---|
| 하루 | $1 |
| 한 달 | $5 |

- 호출마다 시각, 모델명, 입력·출력 토큰 수, 예상 비용을 로컬 파일에 기록한다.
- 호출 **전에** 누적 비용을 확인하고, 한도를 넘으면 호출하지 않고 안내한다.
  - 예: "오늘 사용할 수 있는 예산을 다 썼어요. 내일 다시 이용해 주세요."
- 단가는 OpenAI 공식 가격표를 확인해 설정값으로 관리하고, 확인 날짜를 `조사노트.md`에 남긴다.
- 로컬 예산 제한은 실제 청구액을 완전히 막지 못한다. OpenAI 대시보드의 사용 한도 설정을 함께 권장한다.

## 테스트 시

- 비용이 드는 테스트는 꼭 필요한 최소 횟수만 실행하고, 실행 전에 사용자에게 알린다.
- 같은 질문을 반복 호출하는 자동 테스트 루프를 만들지 않는다.
