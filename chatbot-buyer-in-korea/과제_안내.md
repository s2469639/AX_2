# GUESTLY 과제 안내

## 1. 과제 개요

해외 바이어의 특성과 비즈니스 상황에 맞춰 식당·선물을 추천하는 **RAG 기반 의전 챗봇**을 만든다.
목표는 상용 서비스가 아니라 **LangChain·LangGraph·RAG 기반 추천 챗봇을 안정적으로 구현**하는 것이다.

## 2. 학습 목표

1. LangChain으로 문서 로딩, 분할, 임베딩, 벡터 저장 과정을 구성할 수 있다.
2. Chroma에서 메타데이터 필터와 임베딩 유사도 검색을 함께 사용할 수 있다.
3. 유사도 점수의 의미를 이해하고, 실험으로 근거 부족 기준을 정할 수 있다.
4. LangGraph로 조건부 분기(질문 유형, 근거 확인, 1회 재검색)를 구현할 수 있다.
5. 원본 문서의 출처(파일명·소제목·줄 번호)를 추적해 답변에 표시할 수 있다.
6. API 비용을 줄이는 설계(임베딩 재사용, 호출 제한, 예산 확인)를 적용할 수 있다.
7. Streamlit으로 대화 기록을 유지하는 채팅 화면을 만들 수 있다.

## 3. 실행 방법 (구현 후 사용 예정)

> 아래 명령은 코드 작성이 끝난 뒤 사용한다. 파일 이름은 구현 단계에서 바뀔 수 있다.

**1) 가상환경 만들기 (Windows PowerShell)**

```bash
python -m venv .venv
```

```bash
.venv\Scripts\Activate.ps1
```

**2) 패키지 설치**

```bash
pip install -r requirements.txt
```

**3) 환경변수 설정**

`.env.example`을 복사해 `.env`를 만들고, `OPENAI_API_KEY` 값을 직접 입력한다.
`.env`는 절대 공유하거나 커밋하지 않는다.

**4) 문서 임베딩 (문서가 바뀌었을 때만)**

```bash
python ingest.py
```

**5) 앱 실행**

```bash
streamlit run app.py
```

## 5. 평가 항목

### 기능 테스트

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 식당 추천 | 조건에 맞는 식당 2~3곳 + 이유 + 가격대 + 주의사항 + 출처 |
| 2 | 선물 추천 | 조건에 맞는 선물 2~3개 + 이유 + 가격대 + 주의사항 + 출처 |
| 3 | 통합 추천 | 식당·선물을 한 답변에 함께 정리 |
| 4 | 예산 초과 제외 | 예산을 넘는 후보가 추천에 나오지 않음 |
| 5 | 후속 질문 | "더 저렴한 곳" 등에서 바뀌지 않은 조건(지역·인원 등) 유지 |
| 6 | 근거 부족 | 관련 없는 질문에 모델 호출 없이 "문서에서 찾지 못했어요" 반환 |
| 7 | 재검색 제한 | 재검색이 최대 1회만 실행됨 |
| 8 | 임베딩 중복 방지 | 문서 변경 없이 `ingest.py` 재실행 시 임베딩 호출 0회 |
| 9 | 비용 제한 | 한도 초과 시 호출 전에 차단하고 안내 메시지 표시 |

### 품질 기준

- 출처가 실제 원본 Markdown의 소제목·줄 번호와 일치한다.
- 문서에 없는 식당·선물을 만들어내지 않는다.
- 국가별 고정관념에 기대지 않고, 최신 확인이 필요한 정보를 단정하지 않는다.
- 오류 메시지가 쉬운 한국어로 되어 있다.
- 모든 함수에 한국어 주석이 있다.
- `.env`와 API 키가 코드·커밋에 노출되지 않는다.
- 검증 과정과 실험 결과가 `조사노트.md`에 기록되어 있다.
