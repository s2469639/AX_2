■ 📥 프롬프트 1 · 기획서를 만든다  (📍 Code 탭 (blog 폴더 · uplika 연결))
[링크 또는 메모]를 읽고, 이걸 내 블로그 글로 쓴다면
어떤 글이 될지 기획서 한 장으로 정리해줘.
누구에게, 무슨 문제를, 어떤 순서로 풀지, 제목 후보 3개까지.

■ 🔑 프롬프트 2 · 메인 키워드  (📍 Code 탭 (blog 폴더 · uplika 연결))
위 기획서의 주제를 1~2단어로 줄인 메인 키워드 후보 3개를 뽑아줘.
제목이 아니라 검색해볼 입구라 넓게 잡아줘.

■ 🔎 프롬프트 3 · 연관 키워드  (📍 Code 탭 (blog 폴더 · uplika 연결))
아래 주소의 [메인키워드] 자리에 위 메인 키워드 3개를 하나씩 넣어서 열어보고,
돌아온 목록에서 내 기획서와 맞는 걸 3개 골라
기획서 맨 위에 「최종 키워드」로 적어줘.
아무것도 안 돌아오는 말은 한 단어 줄여서 다시 넣어봐.
https://ac.search.naver.com/nx/ac?q=[메인키워드]&st=100&r_format=json

■ ✍️ 프롬프트 4 · 블로그 글을 쓴다  (📍 Code 탭 (blog 폴더 · uplika 연결))
기획서와 최종 키워드 3개로 블로그 글을 써줘.
제목과 첫 문단 첫 줄에 키워드를 넣고, 본문은 1,500자 이상,
소제목 3~4개는 ## 로, 키워드는 전체에서 3~5번만.
사진 넣을 자리는 [사진: 무슨 사진] 으로 한 줄에 하나씩 표시해줘.
말투는 [내가 쓴 글 링크 또는 @reference/내글1.html] 를 참고하고,
마지막에 태그 12개를 뽑아줘.

■ 🚀 프롬프트 5 · 업로드  (📍 Code 탭 (blog 폴더 · uplika 연결))
위에서 쓴 글을 uplika 로 네이버 블로그에 올려줘. 조건:
1. 카테고리는 [내 카테고리] 로.
2. 본문은 내가 쓴 구조 그대로 넘겨줘. 블로그 폼으로 다시 배치하지 마.
   ## 같은 기호도 지우지 마.
3. 사진: [올릴 링크를 줘 / 저작권 없는 무료 사진으로 찾아줘].
   들어갈 자리에는 ![사진](media:아이디) 를 한 줄로만 놔줘.
4. 태그는 뽑아 둔 12개 그대로. # 없이.
5. 먼저 비공개로 올려줘. 내가 보고 괜찮다고 하면 공개로 바꿔줘.
올라가면 글 주소를 알려줘.

3. 카테고리 [맛집], 해시태그는 글 끝 그대로, 블로그 폼으로 다시 배치하지 마.

■ 📋 프롬프트 — 블로그 → 인스타  (📍 Code 탭 (blog 폴더 · uplika 연결))
[@글/파일.html 또는 블로그 글 주소] 내용을 인스타 캐러셀로 바꿔줘.
1. 5장 구성: 1장 표지(큰 제목), 2~4장 핵심 3가지, 5장 정리 + "자세한 건 블로그에"
2. 캡션: 첫 줄은 훅, 2,200자 이내, 해시태그는 5개 이하
3. 사진은 내 사진을 쓸게. 장마다 무슨 사진이 맞는지 알려주고 올릴 링크를 줘.
4. 바로 올리지 말고 미리보기를 먼저 보여줘.
   내가 좋다고 하면 uplika 로 [내일 저녁 8시]에 예약해줘.
