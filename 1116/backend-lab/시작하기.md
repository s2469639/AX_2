# backend-lab — 백엔드 · DB · Supabase 실습 폴더

1. `backend-lab.zip` 을 **바탕화면**에 압축 풀기
2. Claude 데스크톱 앱 → **Code** 탭 → 폴더 선택 → `backend-lab`
3. 교안의 프롬프트를 복사 → Code 탭에 붙여 넣기 → Enter

| 폴더 | 실습 |
|---|---|
| `01_CSS_vs_Tailwind/` | 같은 카드를 CSS 와 Tailwind 로 비교 |
| `02_로직설계/` | 기능 로직 설계서 양식 · 예시 |
| `03_디버깅/` | 일부러 버그를 넣은 페이지 (고쳐 보기) |
| `04_DB설계/` | 엑셀 한 장짜리 표 → 테이블로 나누기 |
| `05_Supabase/` | SQL 예시 · MCP 자연어 명령 카드 · `.env.local` 예시 |
| `06_가상환경/` | 가상환경 확인 실습 안내 |
| `07_오늘과제/` | **오늘 과제** — 내 서비스 + Supabase 연동 (안내 · 양식 · 프롬프트 순서) |

## 🔐 절대 규칙 (오늘 내내)
- **API 키 · 비밀번호는 `.env.local` 파일에 내 손으로만** 입력해요.
- 채팅 · Claude · 스크린샷 · 단톡방 · GitHub 에 **키를 붙여 넣지 않아요.**
- **`sb_secret_` 으로 시작하는 키(비밀 키)는 오늘 쓰지 않아요.**
- 실습 데이터는 모두 **(가상)** 연습 데이터예요. **회사 · 고객의 실제 데이터는 넣지 않아요** — 회사 데이터를 쓰려면 반드시 회사(담당 부서)에 먼저 확인해요.
