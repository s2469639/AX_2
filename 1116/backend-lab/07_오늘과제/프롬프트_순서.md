## ② 데이터 설계 → SQL 초안
서비스_기획.md 를 읽고 Supabase 에 쌓을 데이터를 설계해서 데이터설계.md 로 저장해 줘.
1) 표 · 칸 · 타입 · 규칙(not null, unique, references, check) 표
2) 각 표의 RLS 규칙 — 누가(publishable / 서버) 무엇을(읽기 · 추가 · 고치기) 할 수 있는지와 이유
3) 쌓지 않을 데이터와 이유
4) 위 설계대로 표를 만드는 SQL (create table + enable row level security + 정책 + grant) 과 (가상) 데이터 5줄 넣는 SQL — 파일로만 저장하고 실행하지 마
- 개인정보 칸은 꼭 필요한 것만, 실제 회사 · 사람 이름 금지

## ④ 앱 만들고 Supabase 연결 (my-service 폴더)
서비스_기획.md 와 데이터설계.md 대로 Next.js 앱을 만들어 줘. (없으면 npx create-next-app@latest my-service --yes)
.env.local 에 NEXT_PUBLIC_SUPABASE_URL 과 NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY 를 내가 직접 넣었어. 파일 내용은 읽거나 출력하지 마.
1) lib/supabase.ts — 환경 변수 이름만 사용
2) app/api/___/route.ts — POST 는 6단계(검사 → 저장 → 201 · 400 · 500), 저장할 때 .select() 를 붙이지 마 (읽기 규칙이 없어서)
3) 입력 폼 화면 — 제출하면 API 로 보내고 서버 메시지를 폼 아래에
4) 목록 화면 — RLS 가 허락한 칸만 읽어서 카드로
5) 비전공자용 한국어 주석 · 개발 서버를 켜서 주소 알려 줘
