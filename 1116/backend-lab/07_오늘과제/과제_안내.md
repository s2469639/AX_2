# 🏠 오늘 과제 — 내 서비스 + Supabase 연동

## 목표
오늘 배운 순서 그대로: **서비스 정하기 → 쌓을 데이터 설계 → Supabase 에 표 만들기 → Next.js 앱과 연결**

## 해야 할 일
1. 내 서비스 **한 문장** — "[누가] [무엇을] 할 수 있는 서비스. 지금은 [불편한 점] 이라서."
2. `서비스_기획.md` — 기능 3개 이하 · 로직 6단계(입력 · 검사 · 처리 · 저장 · 응답 · 예외) + 권한 · 기록
3. `데이터설계.md` — 표 · 칸 · 타입 · 규칙 · RLS · 쌓지 않을 데이터 · SQL
4. Supabase 새 프로젝트에 표 만들기 + (가상) 데이터
5. Next.js 앱(입력 폼 + 목록 + API) 만들고 Supabase 연결
6. 시험 · 보안 점검 → `점검표.md`
7. (선택) Vercel 배포

## 범위
- 표 2~3개 · 기능 3개 이하 · 로그인 없이 · 화면 2~3장
