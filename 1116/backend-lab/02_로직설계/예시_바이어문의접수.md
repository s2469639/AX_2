# 예시 — (가상) 바이어 문의 접수

| 칸 | 내용 |
|---|---|
| 기능 이름 | 바이어 문의 접수 |
| 누가 쓰나 | 아무나 (홈페이지 방문자) — 저장만 가능, 다른 사람 문의는 못 봄 |
| ① 입력 | 회사명(필수), 담당자 이메일(필수, 이메일 형식), 국가(필수), 상품(필수, 목록에서 선택), 수량(필수, 1 이상 정수), 메시지(선택, 1000자 이하) |
| ② 검사 | 필수 칸 비었나 · 이메일 형식 · 수량이 1 이상인가 · 상품이 목록에 있나 |
| ③ 처리 | 같은 이메일 바이어가 있으면 그 바이어로 연결, 없으면 새 바이어 만들기 · 상태 = "신규" |
| ④ 저장 | buyers 표(없을 때만) · inquiries 표(항상) |
| ⑤ 응답 | "문의가 접수되었어요. 영업일 기준 1~2일 안에 연락드릴게요." (접수 번호 함께) |
| ⑥ 예외 | 필수 칸 빔 → "○○을 입력해 주세요" · 수량 0 → "수량은 1개 이상" · 서버 문제 → "잠시 후 다시 시도해 주세요" (자세한 에러 내용은 화면에 보여 주지 않기) |
| 기록 | 접수 시각 · 접수 번호 |
